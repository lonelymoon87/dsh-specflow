# Contributing

This project follows the independent-plugin contribution route documented by DeepSeek Harness. It is not part of the `deepseek-ai/deepseek-harness` monorepo.

1. Open an issue for a behavior or artifact-protocol change before implementing it.
2. Create a focused branch from `main`.
3. Update code, portable skill instructions, templates, and bilingual documentation together when their behavior changes.
4. Run `pnpm run check`.
5. Open a pull request that explains the user-visible behavior and the commands actually run.

Do not include API keys, tokens, generated package archives, or local `.dsh` session data in a contribution.
